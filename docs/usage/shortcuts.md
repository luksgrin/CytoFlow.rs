# Keyboard Shortcuts

On macOS use ++cmd++; on Windows and Linux use ++ctrl++ in its place. Single-key shortcuts are ignored while you are typing in a text field or menu, and while a dialog is open.

## Files

| Shortcut | Action |
|---|---|
| ++cmd+o++ | Add FCS files |
| ++shift+cmd+o++ | Open a workspace (`*.cfw.json`) |
| ++cmd+s++ | Save the workspace (asks for a file name the first time) |
| ++shift+cmd+s++ | Save the workspace as… |

## Gate Tools

Available in the graph window. Tools that need two axes are ignored on a histogram, and the range tool on a 2-D plot.

| Key | Tool |
|---|---|
| **V** | Select / edit gates |
| **R** | Rectangle |
| **P** | Polygon |
| **L** | Lasso (freehand) |
| **E** | Ellipse |
| **Q** | Quadrants |
| **G** | Range (histograms) |

## Drawing and Editing

| Shortcut | Action |
|---|---|
| ++enter++ | Close the polygon being drawn (3 vertices or more) |
| Double-click | Close the polygon being drawn; with the select tool, open the population of the gate under the cursor |
| ++esc++ | Cancel the shape being drawn, or deselect the selected gate |
| Right-click (while drawing) | Cancel the shape being drawn |
| ++delete++ / ++backspace++ | Delete the selected gate (or, if no gate is selected on the plot, the selected population); in the layout editor, delete the selected panel |
| ++alt+left++ | Go to the parent population |

## Plot Navigation

| Shortcut | Action |
|---|---|
| Mouse wheel | Zoom in / out around the cursor |
| Right-drag | Pan |
| ++space++ + drag | Pan |
| **0** | Reset zoom and pan |

## Lists

When the Groups list, Samples list or Populations tree has keyboard focus (click it first):

| Shortcut | Action |
|---|---|
| ++up++ / ++down++ | Select the previous / next group, sample or population |

## Dialogs

| Shortcut | Action |
|---|---|
| ++enter++ | Confirm (name prompts, confirmations, the group and export dialogs) |
| ++esc++ | Cancel |
